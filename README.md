# 🏫 Automatic Energy-Efficient Classroom

## Project Overview

This project demonstrates an automatic energy-efficient classroom using Python and Streamlit.

The system uses simulated sensor inputs to automatically control classroom lights, fan and AC according to student presence, light intensity and temperature.

## Sensors Used

- PIR Sensor - Student presence detection
- LDR Sensor - Light intensity detection
- Temperature Sensor - Temperature monitoring

## Main Features

- Automatic light control
- Automatic fan control
- Automatic AC control
- Energy consumption calculation
- Electricity cost estimation
- Energy saving estimation
- Interactive Streamlit dashboard
- Power consumption chart

## Technologies Used

- Python
- Streamlit
- Pandas
- VS Code
- GitHub
