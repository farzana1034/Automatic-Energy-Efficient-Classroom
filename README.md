# ⚡ Automatic Energy-Efficient Classroom

## 📌 Project Overview

The Automatic Energy-Efficient Classroom is a Python and Streamlit-based simulation designed to demonstrate automatic energy management in a classroom.

The system automatically controls classroom lights and fans based on occupancy, light level, and temperature conditions.

## 🎯 Objectives

- Reduce unnecessary energy consumption
- Automatically control classroom lighting
- Automatically control classroom fans
- Monitor classroom conditions
- Demonstrate energy-efficient operation
- Calculate and analyze energy consumption

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- Matplotlib
- Git
- GitHub
